Assembly x86-64 لمبرمج C

مش محتاج تبقى مبرمج Assembly عشان تبقى Reverser ممتاز — محتاج تبقى قارئ ممتاز. الخبر الحلو: الـ compilers بتستخدم مجموعة صغيرة من الـ instructions (حوالي 30 instruction بيغطوا 95% من الكود). المرحلة دي بتديك الأساس ده، وكمان هتكتب دوال Assembly بإيدك وتناديها من C جوه الصفحة.

قاعدة الـ 32-bit الغريبة

الكتابة في register 32-bit (mov eax, 1) بتصفّر الـ 32 bit العليا من rax أوتوماتيك. لكن الكتابة في 16 أو 8 bit (mov al, 1) مش بتلمس الباقي. عشان كده الـ compilers بتكتب xor eax, eax مش xor rax, rax (أقصر ونفس النتيجة)، وmov edi, edi اللي شفناها في الـ jump table = zero-extend لـ 64-bit.

CF Carryoverflow unsigned (أو borrow في الطرح)jb/jae، adc
OF Overflowoverflow signedjo، jl/jg

cmp a, b = بيحسب a - b ويغيّر الـ flags من غير ما يخزّن النتيجة. test a, b = بيحسب a & b بنفس الطريقة. فـ test eax, eax + jz = if (eax == 0)، وtest al, 1 + jnz = if (x & 1).

اكتب Assembly بإيدك وشغّله! hands-on

الـ GCC بيسمح بـ __asm__ على مستوى الملف: بتكتب دالة كاملة بالـ Assembly، وتعرّف الـ prototype بتاعها في C وتناديها عادي. (التشغيل هنا Linux، فالـ arguments في rdi, rsi, rdx… والرجوع في rax.) عدّل في الكود وشغّل:

#include __asm__( ".intel_syntax noprefix\n" ".text\n" ".globl my_add\n" "my_add:\n" /* int my_add(int a, int b) */ " lea eax, [rdi+rsi]\n" /* eax = a + b */ " ret\n" ".globl my_abs\n" "my_abs:\n" /* int my_abs(int x) */ " mov eax, edi\n" " neg eax\n" /* eax = -x, sets SF */ " cmovs eax, edi\n" /* if result negative, eax = x */ " ret\n" ".globl count_down\n" "count_down:\n" /* long count_down(long n): n + (n-1) + ... + 1 */ " xor eax, eax\n" ".Lloop:\n" " test rdi, rdi\n" " jz .Ldone\n" " add rax, rdi\n" " dec rdi\n" " jmp .Lloop\n" ".Ldone:\n" " ret\n" ".att_syntax prefix\n" ); int my_add(int a, int b); int my_abs(int x); long count_down(long n); int main(void) { printf("my_add(40, 2) = %d\n", my_add(40, 2)); printf("my_abs(-17) = %d\n", my_abs(-17)); printf("my_abs(23) = %d\n", my_abs(23)); printf("count_down(100) = %ld\n", count_down(100)); return 0; }

القسمة والـ Remainder idiv

#include __asm__( ".intel_syntax noprefix\n" ".text\n" ".globl divmod\n" "divmod:\n" /* void divmod(int a, int b, int *q, int *r) */ " mov eax, edi\n" /* dividend in eax */ " mov r8, rdx\n" /* save q pointer (rdx is about to change) */ " cdq\n" /* sign-extend eax into edx:eax */ " idiv esi\n" /* eax = quotient, edx = remainder */ " mov [r8], eax\n" " mov [rcx], edx\n" " ret\n" ".att_syntax prefix\n" ); void divmod(int a, int b, int *q, int *r); int main(void) { int q, r; divmod(47, 5, &q, &r); printf("47 / 5 -> q=%d r=%d\n", q, r); divmod(-47, 5, &q, &r); printf("-47 / 5 -> q=%d r=%d\n", q, r); return 0; }
🔬
idiv نادرة في الكود المعمول له optimization

idiv بطيئة جدًا (عشرات الـ cycles)، فالـ compilers لما المقسوم عليه ثابت بيستبدلوها بـ ضرب في "magic number" + shift. لو شفت mov eax, 0CCCCCCCDh + mul + shr edx, 3 — ده x / 10. هنشوفها بالتفصيل في المرحلة 14.

اقرا الـ Assembly ده reading practice

اتعود تعمل الخطوات دي مع أي دالة: (1) حدد الـ arguments من الـ registers اللي بتتقرا قبل ما تتكتب. (2) حدد الـ loops من الـ back-edges. (3) اكتب كل سطر كـ C pseudo-code. (4) بسّط. جرّب في التمارين اللي تحت.
