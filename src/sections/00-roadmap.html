ليه C؟ وإزاي تذاكر الكورس ده صح

لو هدفك تحليل الـ Malware والـ Reverse Engineering، فـ C مش "لغة كمان تتعلمها" — دي اللغة اللي أغلب الـ Malware والأنظمة اتكتبت بيها، وهي أقرب لغة عالية المستوى للـ Assembly. اللي بيفهم C كويس بيقرا الـ disassembly كأنه بيقرا كود.

🧬

الـ Malware مكتوب بـ C/C++

أغلب الـ Ransomware والـ Loaders والـ RATs والـ Rootkits مكتوبة بـ C أو C++. لما تفتح sample في Ghidra، الـ decompiler بيرجّعلك pseudo-C — ولازم تقراه وتفهمه بسرعة.

🧠

C = نموذج الذاكرة الحقيقي

Pointers، Stack، Heap، Structs، Padding، Endianness — كل ده مش "تفاصيل"، ده اللي بتشوفه بعينك في الـ debugger. C بتجبرك تفهمه.

⚙️

كل سطر ليه Assembly

في الكورس ده، كل مثال عليه زرار ⚙ ASM بيوريك الـ compiler حوّله لإيه، بمستويات optimization مختلفة. ده بالظبط التمرين اللي بيعمل Reverser محترف.

🛡️

فهم الثغرات = فهم الهجوم

Buffer overflow، use-after-free، integer overflow… هتفهم ليه بتحصل في الكود، وإزاي تكتشفها وأنت بتحلل binary، وإيه الحمايات الموجودة ضدها.

خطة الكورس 5 أجزاء

01

الأساسيات (01 → 06)

الأدوات والـ compilation وGDB، الأنواع والتمثيل الثنائي، العمليات والـ bitwise، التحكم في التدفق، الدوال (وsetjmp/longjmp)، الـ arrays والـ strings والـ VLAs. متستعجلش هنا — كل اللي جاي مبني عليه.

02

الذاكرة والبوينترز (07 → 12)

قلب لغة C وقلب الـ RE: pointers، تخطيط الذاكرة، الـ heap، الـ hash tables والـ trees، الـ structs والـ padding، الـ preprocessor وC11/C23، وقراءة الملفات الـ binary وerrno.

03

C تحت المجهر (13 → 17)

Assembly x86-64، إزاي كل تركيبة C بتتحول لـ Assembly، الـ calling conventions، الـ Undefined Behavior والثغرات، ملفات PE/ELF، وC على Windows زي ما بتشوفها في الـ samples.

04

C على مستوى النظام (18 → 22)

الـ threads والتزامن، الـ processes والـ signals والـ pipes، الـ sockets وإزاي الـ C2 بيتكلم، المكتبات (.so وDLLs وsideloading وLD_PRELOAD)، وC++ زي ما بتشوفها في الـ binary (vtables، RTTI، STL).

05

المشاريع والمرجع (23 → النهاية)

مشاريع حقيقية بأدوات بيستخدمها المحللين: hexdump، strings extractor، XOR decoder، PE parser، crackme تكتبه وتكسره بنفسك، وVM interpreter صغير.

إزاي تستخدم الصفحة workflow

▶

شغّل الكود

زرار تشغيل بيعمل compile حقيقي بـ gcc 15.2 (وg++ 15.2 لأمثلة C++) على Compiler Explorer (Linux x86-64) ويرجعلك المخرجات.

⚙

شوف الـ Assembly

زرار ASM بيعرض الـ Assembly بصيغة Intel، وتقدر تبدّل بين -O0 و-O1 و-O2 و-Os.

🎯

حل التحديات

كل تحدي بيتصحح أوتوماتيك: الكود بيتعمله compile ويتشغل، والمخرجات بتتقارن بالمطلوب حرف بحرف.

🌐
التشغيل محتاج إنترنت

الكود بيتبعت لـ godbolt.org (Compiler Explorer — خدمة مجانية مفتوحة المصدر) عشان يتعمله compile. متحطش أي بيانات سرية في الكود. لو مفيش إنترنت، الأمثلة بتعرض مخرجات متحقق منها مسبقًا بنفس الـ compiler.

🧪
قاعدة المعمل

كل الأكواد في الكورس ده تعليمية وآمنة. لما تبدأ تحلل samples حقيقية، اشتغل دايمًا جوه Virtual Machine معزولة (مثلًا FLARE-VM أو REMnux) من غير shared folders ومع snapshot نضيف — ومتشغلش sample على جهازك الأساسي أبدًا.

💡
القاعدة الذهبية للـ Reverser

بعد كل مثال اسأل نفسك: "لو شفت الـ Assembly ده من غير الكود، كنت هعرف أرجّعه C؟" — اضغط ASM، غطّي الكود بإيدك، وحاول. التمرين ده لوحده هيعمل منك محلل.
