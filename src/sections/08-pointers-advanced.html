Pointers متقدمة: void*، Function Pointers، والـ Indirect Calls

الـ malware المحترف نادرًا ما بينادي الدوال بأسمائها. بيحل عناوينها وقت التشغيل ويخزنها في function pointers، وبيعمل جداول منها. في الـ disassembly ده بيظهر call rax أو call qword ptr [rbx+18h] — ولو مش فاهم الـ function pointers، الـ indirect calls دي هتبقى حيطة سد.

void* : الـ Pointer العام generic

void * = عنوان من غير نوع. أي pointer بيتحول له ومنه تلقائي، لكن مينفعش تعمل له dereference أو arithmetic مباشرة — لازم تعمله cast لنوع الأول. ده اللي بيخلي malloc وmemcpy وVirtualAlloc يشتغلوا مع أي نوع.

Function Pointers callbacks

اسم الدالة لوحده = عنوانها في الذاكرة (في الـ .text). تقدر تخزنه في متغير وتناديه بعدين. استخدم typedef عشان تخلي الكود مقروء.

#include #include #include typedef int (*transform_fn)(int); /* type: pointer to int f(int) */ static int to_upper(int c) { return (c >= 'a' && c <= 'z') ? c - 32 : c; } static int rot13(int c) { if (c >= 'a' && c <= 'z') return 'a' + (c - 'a' + 13) % 26; if (c >= 'A' && c <= 'Z') return 'A' + (c - 'A' + 13) % 26; return c; } static void apply(char *s, transform_fn fn) { /* callback */ for (; *s; s++) *s = (char)fn(*s); } /* qsort needs a comparator callback */ static int cmp_str(const void *a, const void *b) { const char *const *sa = a, *const *sb = b; return strcmp(*sa, *sb); } int main(void) { char msg[] = "beacon interval"; apply(msg, to_upper); printf("%s\n", msg); apply(msg, rot13); printf("%s\n", msg); transform_fn chosen = rot13; /* store the address */ printf("chosen('A') = %c\n", chosen('A')); const char *names[] = { "svchost", "explorer", "lsass", "csrss" }; qsort(names, 4, sizeof names[0], cmp_str); for (int i = 0; i < 4; i++) printf("%s ", names[i]); printf("\n"); return 0; }

Dispatch Tables: جدول دوال indirect calls

بدل switch ضخم: array من function pointers، والـ index بيختار الدالة. ده نفس شكل الـ vtables في C++، وجداول الأوامر في الـ backdoors، وجدول الـ IAT (Import Address Table) في الـ PE.

typedef int (*op_fn)(int, int); static int add(int a, int b) { return a + b; } static int sub(int a, int b) { return a - b; } op_fn table[2] = { add, sub }; int run(int idx, int a, int b) { return table[idx](a, b); } add: lea eax, [rdi+rsi] ret sub: mov eax, edi sub eax, esi ret run: movsx rdi, edi ; idx -> 64-bit mov rax, QWORD PTR table[0+rdi*8] ; load fn ptr mov edi, esi ; shift args: mov esi, edx ; a, b jmp rax ; indirect tail call table: ; in .data .quad add .quad sub
#include typedef void (*handler_fn)(const char *arg); static void h_sleep(const char *a) { printf(" sleeping %s s\n", a); } static void h_echo (const char *a) { printf(" echo: %s\n", a); } static void h_exit (const char *a) { (void)a; printf(" exiting\n"); } static const struct { unsigned char id; handler_fn fn; } handlers[] = { { 0x01, h_sleep }, { 0x02, h_echo }, { 0x7F, h_exit }, }; static void dispatch(unsigned char id, const char *arg) { for (size_t i = 0; i < sizeof handlers / sizeof handlers[0]; i++) { if (handlers[i].id == id) { handlers[i].fn(arg); /* indirect call */ return; } } printf(" unknown command 0x%02X\n", id); } int main(void) { dispatch(0x02, "hello"); dispatch(0x01, "30"); dispatch(0x55, "?"); dispatch(0x7F, ""); return 0; }

إزاي تحل indirect call

لما تلاقي call rax: (1) ارجع لورا وشوف rax اتحمل منين — من جدول؟ من struct؟ من نتيجة GetProcAddress؟ (2) لو جدول ثابت في .data/.rdata، كل entry فيه عنوان دالة — اتبعها. (3) لو مش واضح static، حط breakpoint في x64dbg على الـ call وشوف rax = أنهي دالة وقت التشغيل. وفي Ghidra/IDA تقدر تضيف الـ reference يدويًا.

Dynamic API Resolution — زي ما الـ Malware بيعمل GetProcAddress

البرامج العادية بتستورد الـ APIs في الـ Import Table (ظاهرة لأي أداة). لكن ممكن تحمّل DLL وتجيب عنوان أي دالة وقت التشغيل وتخزنه في function pointer. الـ malware بيعمل كده عشان يخبي الـ APIs المشبوهة من الـ imports. ده كود Windows عادي وموثق (للقراية، مش هيشتغل على Linux):

#include #include /* Function-pointer type matching the real MessageBoxA signature */ typedef int (WINAPI *MessageBoxA_t)(HWND, LPCSTR, LPCSTR, UINT); int main(void) { HMODULE user32 = LoadLibraryA("user32.dll"); /* load at runtime */ if (user32 == NULL) return 1; MessageBoxA_t pMessageBoxA = (MessageBoxA_t)(void *)GetProcAddress(user32, "MessageBoxA"); if (pMessageBoxA == NULL) return 1; pMessageBoxA(NULL, "Resolved at runtime", "demo", MB_OK); /* call rax */ FreeLibrary(user32); return 0; }

علامات في الـ sample

(1) Import table فيها LoadLibraryA وGetProcAddress وشوية APIs بس = غالبًا بيحل الباقي dynamic. (2) strings لأسماء APIs (مشفرة أحيانًا) بتتبعت لـ GetProcAddress. (3) أو مفيش strings خالص وفيه hashes (زي ROR-13 في المرحلة 03) والكود بيمشي على الـ export table بنفسه. في كل الحالات النتيجة متخزنة في متغيرات global — سمّيها باسم الـ API في Ghidra وكل الـ call [rip+X] هتبقى مقروءة.
